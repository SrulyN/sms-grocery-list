Personal project

One number.
One shared grocery list.

My wife and I kept arriving at the store with two different lists on two different phones. So we text one number instead. Whatever either of us sends lands on the same list.

Try it

The panel on the right is the real thing, running in your browser. Type a grocery item and send it. Then try sending something already on the list and watch it merge instead of duplicating.

This demo runs the matching logic on its own so you can try it without a phone number. The deployed version adds a language-model step that handles messier phrasing, and sends the replies as actual text messages.

What it understands

anything
Adds it. Several at once works: milk, eggs, 2 lb chicken
list
Sends the whole list back
done
Clears it and starts the next trip
undo
Brings back a list cleared by mistake
drop milk
Takes one thing off
help
Lists the commands

How it's built

A single serverless function on Cloudflare Workers, a small SQLite database, and a language model that decides when two entries mean the same thing. "2% milk" and "a gallon of milk" are the same item. "whole milk" and "oat milk" are not.

Clearing the list doesn't delete anything. It closes the current trip and opens a new one, which is what makes undo possible.

Only phone numbers added to the household in advance get a reply. Every other number is ignored, so the system cannot message anyone who wasn't deliberately added to it.
